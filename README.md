# Demo Mode 1 · Northstar ID

Standalone fictional account-security page for ChocoScan's browser safety demo catalogue. The layout includes an account review form, status panel, and a reminder modal.

All form controls are visual-only. No entered values are submitted, stored, or transmitted. The buttons only change local interface state.

## Manual Netlify deploy
1. Download this repository as a ZIP and extract it.
2. In Netlify, choose manual deploy.
3. Drag the project contents into the deploy area, keeping `index.html`, `assets/`, and `netlify.toml` together.

## Project files
- `index.html`: standalone page
- `assets/css/style.css`: responsive styling
- `assets/js/app.js`: local-only interactions
- `assets/favicon.svg`: tab icon
- `netlify.toml`: static hosting configuration
